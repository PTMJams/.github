## PTM Jams

Game jams and music jams, mostly with Godot.

**PTM, Pass The Mix**, is a musical exquisite corpse: each artist gets 1 h 30 on the track, with the default instruments of Ableton Live 12 Suite, then passes it on. Five rounds, then the mixing and the mastering are done together.

Games made during game jams:
- GMTK2022: The Island, the vagaries of nature (2022, Lua)
- IcoJam-2023: Iceberg Panic! (2023, GDScript)
- LD55: Fiesta De Las Quimeras! (2024, GDScript)
